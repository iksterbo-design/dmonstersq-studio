Opening it on Android

Fastest — no APK needed. Copy this folder to your phone, open a file manager, tap START-HERE.html → choose Chrome. Both studios run. For the installable version (home-screen icon, offline) host the folder on any HTTPS site — e.g. GitHub Pages — then open it in Chrome and pick Add to Home screen.
About F-Droid: you can't open a folder in F-Droid, and you can't upload an APK to it either — F-Droid builds apps from source on its own servers. To get in the official F-Droid app you publish the source and submit the recipe (already written in fdroid/metadata/). To keep it personal, build the APK and either sideload it or host your own F-Droid repo.
The one missing piece: there is no .apk in this folder yet, because building one needs Java + the Android SDK, which aren't installed here. Two ways to get it without installing anything:
  • Push the folder to GitHub → Actions → Build Android APK → Run workflow (the workflow is included) → download the APK artifact.
  • Or host the app, paste the URL into pwabuilder.com → Android → download a signed APK.

Run it on this PC

cd D-MONSTERS-Q-STUDIO
python serve.py
It prints a http://192.168.x.x:8000 URL — open that on your phone over Wi-Fi and both studios work immediately. (Installing as an app needs HTTPS.)
